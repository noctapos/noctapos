Tambah lewat “+ Tambah kategori baru”. Ubah nama / hapus di kartu Kelola kategori di bawah.

Gambar otomatis dipotong mengisi kotak seukuran template (sama seperti kartu hijau/oranye). Ukuran ideal 1200×630 px (rasio 1,9:1), tulisan penting di tengah.

Pakai Heading untuk subjudul. Gambar: pakai tombol gambar (link https:// atau assets/), jangan tempel/seret file gambar langsung.

    Kelola kategori

    Kategori tampil sebagai filter di halaman Artikel dan Pusat Panduan. Kategori yang masih dipakai konten tidak bisa dihapus; ubah namanya kalau mau digabung ke kategori lain.

    Semua konten

    Mode tes: konten tersimpan di browser ini saja. Ekspor JSON untuk cadangan dan untuk pindah ke database Cloudflare nanti. sitemap.xml diunggah ke folder utama situs, lalu kirim ke Google Search Console.
