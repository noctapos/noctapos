Bikin Artikel NoctaPOS

Isi form, klik tombol, dapat file artikel + kode kartunya. Taruh file ini di folder Web (sejajar index.html) supaya preview-nya pakai desain asli.

1. Isi artikel

Cara nulis: paragraf dipisah baris kosong. Subjudul: awali ## . Daftar: awali tiap baris - (atau 1. ). Tebal: **teks**. Tautan: [teks](https://...).

2. Preview

3. Simpan hasilnya

  1. Pindahkan file yang terdownload ke folder artikel/.
  2. Buka artikel.html di VS Code, tekan Ctrl+F, cari id="blogGrid">, lalu paste kode kartu tepat setelahnya.
  3. Simpan, buka di browser, cek. Selesai.
